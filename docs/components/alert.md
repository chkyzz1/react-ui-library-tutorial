# Alert 组件分析

## 组件概述与功能定位
`Alert` 用于展示简短反馈信息，支持 `info/success/error/warning` 四种状态，并提供 `title` 与 `closable` 以覆盖通知和提示两类场景。

## 核心接口设计
- `kind`：类型枚举，控制左侧色条语义色
- `title`：标题内容，存在时展示标题+描述双层结构
- `closable`：是否可关闭，内部用状态管理显示与隐藏

## 关键技术实现
- 通过 `kind -> color` 映射实现语义色统一管理
- 组件容器仅使用浅底色，语义依赖左侧 `border-left`，降低视觉噪音
- 关闭行为用本地 `useState`，无需父组件管理

## 与 Ant Design 对比
- 相同点：语义类型命名与浅底+色条风格一致
- 差异点：当前版本 API 更轻量，未包含 icon/description 独立字段与 Banner 模式

## 面试常见问题
- 为什么不用纯背景色？
  - 纯色块在高密度页面冲击过强，浅底+色条可读性更稳，适合企业后台。
- `closable` 是否应受控？
  - 当前是非受控隐藏，适合轻交互；复杂场景可扩展 `onClose`+受控 `open`。
