# Select 组件分析

## 组件概述与功能定位
`Select` 用于结构化选项输入，当前版本支持下拉面板、搜索过滤与清空能力。

## 核心接口设计
- `options`：`{ label, value }[]`
- `value/defaultValue`：受控与非受控双模式
- `showSearch`：输入过滤选项
- `allowClear`：清空当前值

## 关键技术实现
- 点击外部关闭：`ref + document click` 监听
- `useMemo` 对选项过滤结果做缓存
- 单向 `triggerChange` 封装，统一控制内外状态同步

## 与 Ant Design 对比
- 相同点：核心使用方式与 `options` 驱动思想一致
- 差异点：暂未实现多选、标签模式与虚拟滚动

## 面试常见问题
- 为什么过滤逻辑放在组件内？
  - 对中小数据量更易用；大数据可扩展远程搜索与防抖。
- 外部点击关闭为什么不能只靠冒泡？
  - 下拉层与触发器交互复杂，显式监听文档点击更稳定。
